## Requirements

- React 19 or newer for the React components.
- Tailwind CSS v4 if you want Tailwind utilities. The plain CSS works without it.

## Install the packages

```bash
pnpm add @component-library/ui @component-library/styles @component-library/tokens
```

`ui` holds the React components. `styles` and `tokens` hold the CSS, so on a site without React you only need those two.

## Set up the styles

### With Tailwind

Import the Tailwind entry at the top of your main stylesheet. It brings in Tailwind, the theme and every component's styles:

```css
@import "@component-library/styles/tailwind.css";
```

Then point Tailwind at the components so it generates the classes they use:

```css
@source "../node_modules/@component-library/ui/src";
```

### Without Tailwind

Import the plain CSS entry instead. This gives you the theme, a base reset and the CSS-only `cl-*` components:

```css
@import "@component-library/styles";
```

## Dark mode

Dark mode turns on when the `dark` class (or `data-theme="dark"`) is on a parent element, usually `<html>`. With Next.js, `next-themes` handles this for you:

```tsx
import { ThemeProvider } from "next-themes";

<ThemeProvider attribute="class" defaultTheme="system" enableSystem>
  {children}
</ThemeProvider>;
```

## Root providers

Two components need something added once, near the root of your app:

- **Tooltip** needs a `TooltipProvider` around the app.
- **Toast** needs a `<Toaster />` somewhere on the page.

```tsx
import { Toaster, TooltipProvider } from "@component-library/ui";

<TooltipProvider>
  {children}
  <Toaster />
</TooltipProvider>;
```

## Use a component

```tsx
import { Button } from "@component-library/ui";

export default function Page() {
  return <Button>Click me</Button>;
}
```
