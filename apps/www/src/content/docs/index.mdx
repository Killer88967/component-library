## What's included

- **Tokens**: colors, spacing, radius, type and motion as CSS variables, JSON and TypeScript.
- **Styles**: a base layer and CSS-only components that work in plain HTML.
- **UI**: React components built on the same CSS.
- **Utils**: framework-free TypeScript helpers.

## Using the CSS

With Tailwind v4, import the Tailwind entry in your main stylesheet:

```css
@import "@component-library/styles/tailwind.css";
```

Without Tailwind, import the plain CSS entry instead:

```css
@import "@component-library/styles";
```
