## Usage

```tsx
import { Checkbox } from "@component-library/ui";

<Checkbox id="terms" />;
```

## CSS only

A native checkbox, so it works in forms with no JavaScript:

```html
<input type="checkbox" class="cl-checkbox" id="terms" />
<label class="cl-label" for="terms">Accept terms</label>
```
