## Usage

```tsx
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@component-library/ui";

<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>This action cannot be undone.</DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>;
```

Pass `showCloseButton={false}` to `DialogContent` to hide the corner close button.

## CSS only

A native `<dialog>`. A button with `data-dialog-open="<id>"` opens it, anything with `data-dialog-close` closes it, and so do Escape and a click on the backdrop. It needs the small runtime script; see [Installation](/docs/installation#css-only-components).
