## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@component-library/ui";

<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Place content for the popover here.</PopoverContent>
</Popover>;
```

## CSS only

Uses the browser's `popover` attribute, so opening, closing and clicking outside work with no JavaScript. The runtime only places it next to its button; see [Installation](/docs/installation#css-only-components). Set `data-side` and `data-align` to change where it goes.
