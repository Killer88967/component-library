## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@component-library/ui";

<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem variant="destructive">Log out</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>;
```

## CSS only

A native popover with `role="menu"`. The runtime adds arrow-key navigation, type-to-jump and closes the menu when an item is picked. Use `role="menuitemcheckbox"` or `role="menuitemradio"` with `aria-checked` for checkable items. It needs the small runtime script; see [Installation](/docs/installation#css-only-components).
