## Usage

```tsx
import { NativeSelect, NativeSelectOption } from "@component-library/ui";

<NativeSelect>
  <NativeSelectOption value="light">Light</NativeSelectOption>
  <NativeSelectOption value="dark">Dark</NativeSelectOption>
</NativeSelect>;
```

Use [Select](/docs/components/select) when you need custom items, like icons or checkmarks. Use Native Select for plain lists, especially in forms and on mobile.
